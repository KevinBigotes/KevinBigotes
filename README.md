### 🚀 Proyectos Destacados

* 🎧 **MoodTune:** Aplicación móvil estilo "Letterboxd" para canciones. Creada con React Native, Expo, Supabase y la API de Spotify.
* 🕹️ **Juego "I Wanna Be The Guy":** Plataformero *hardcore* 2D en GameMaker con físicas de alta precisión, animaciones fluidas y batallas contra jefes.
* 👾 **Fiebre del Neón & Flux:** Juego arcade multijugador 3D para móviles (Unity/C#) y un título espacial incremental 2D con árboles de evolución.
* 🧠 **Reconocimiento Óptico (OCR):** Aplicación en Python impulsada por TensorFlow y redes neuronales convolucionales para el reconocimiento de texto y dígitos.
